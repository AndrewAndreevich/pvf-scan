# PVF Scan

Press-release page for PVF Scan: artworks in super resolution, sculpture in 3D, studios and exhibition halls
over time, the park as a 3D map, and the scan pipeline (cloud or residence).

Live: https://pvf.asia/scans/ (served from the pvf_site repo, folder `scans/`; copy it there with `sh tools/publish.sh`, then commit and push pvf_site).
Also at https://andrewandreevich.github.io/pvf-scan/

Static site, no build: `index.html`, `styles.css`, `main.js`, images in `assets/`.
Content comes from the LOCO Arts proposal (https://andrewandreevich.github.io/loco-arts-proposal/).
Run locally: `python -m http.server` in this folder.
