# PVF Scan

Press-release page for PVF Scan: artworks in super resolution, sculpture in 3D, studios and exhibition halls
over time, the park as a 3D map, and the scan pipeline (cloud or residence) with a price estimate.

Live: https://andrewandreevich.github.io/pvf-scan/

Static site, no build: `index.html`, `styles.css`, `main.js`, images in `assets/`.
Content and prices come from the LOCO Arts proposal (https://andrewandreevich.github.io/loco-arts-proposal/), rate $40/h.
Run locally: `python -m http.server` in this folder.
